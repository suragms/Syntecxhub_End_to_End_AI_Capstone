# Supported commands

- `Hello Sura`, `What can you do?`
- `Open Notepad`, `Open Calculator`, `Open Paint`, `Open File Explorer`, `Open Windows Settings`
- `Open Google`, `Open YouTube`, `Open GitHub`
- `Search Google for artificial intelligence` / `Search for Python programming`
- `What time is it?`, `What is today's date?`, `What day is today?`
- `Help`, `Log out`, `Exit assistant`, `Stop listening`

Natural-language shell commands, deletion, scripts, registry changes, and arbitrary URLs are not supported.
