# Reproducible demo

1. Start `python main.py` and confirm the Welcome screen.
2. Select Start and allow camera access.
3. Present one face until **Face Presence Check Passed — Demo Access** appears. This is not identity authentication.
4. Continue to the dashboard and type `Hello Sura`.
5. Try `Open Notepad`, `Search Google for artificial intelligence`, and `What time is it?`.
6. Test the microphone when a supported device/backend is available; typed input remains the fallback.
7. Select Log out and confirm the Welcome screen returns.
